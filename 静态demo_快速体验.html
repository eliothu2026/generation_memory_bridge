先说明一下 · 这是一个演示

你正在看的是一个纯静态、0 依赖的演示:用一段预录的示例口述(农村长辈回忆「大槐树」)逐段回放,让你零成本先感受产品的使用流程。

它与完整产品同款界面与交互;但为了双击即开,这里不调用任何 AI、不联网、无需后端或 API Key,右侧的"实时整理"是预先录好的结果回放。

完整版还支持:真实多会话(持久化)、真实 DeepSeek 分析、录音上传与实时麦克风语音输入、模型热配置等,详见项目 README。
